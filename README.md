# 🌿 Greenden Website

Greenden is a simple and modern plant shopping website designed to help users explore and discover beautiful plants for their homes and gardens. The website features a clean, responsive, and user-friendly design.

## ✨ Features

* 🌱 Modern and attractive user interface
* 📱 Responsive design for different screen sizes
* 🪴 Plant product showcase
* 🔍 Easy navigation
* 💚 Clean and beginner-friendly design
* 📩 Contact and newsletter sections

## 🛠️ Technologies Used

* HTML5
* CSS3
* Tailwind CSS

## 📸 Website Pages

* Home Page
* Products Page
* Contact Page

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone <repository-link>
```

2. Open the project folder.

3. Open the `index.html` file in your browser.

## 🎯 Purpose

This project was created as a practice project to improve my front-end web development skills, especially in HTML, CSS, and Tailwind CSS.
